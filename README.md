# Tu Chef Personal

App móvil que genera recetas a partir de los ingredientes que tengas.

## Funcionalidades

- Login
- Introduces los ingredientes disponibles y te genera recetas
- Historial de recetas guardadas
- Búsqueda y planificación de recetas

## Tecnologías

Android Studio, Java, XML

## Estructura

```text
tu-chef-personal/
├── app/src/main/java/    → lógica
├── app/src/main/res/layout/  → pantallas
└── README.md
```

## Instalación

```bash
git clone URL_DEL_REPOSITORIO
```

Abre el proyecto con Android Studio, sincroniza y ejecuta en un emulador o dispositivo.

# Problema Barberia

Implementación del problema clásico de concurrencia de la barbería: clientes que llegan, barberos que los atienden y una sala de espera con sitio limitado.

## Funcionalidades

- Llegada de clientes en distintos momentos
- Atención por barberos disponibles
- Gestión de la sala de espera
- Sincronización entre hilos

## Tecnologías

JavaScript, HTML5, CSS3

## Estructura

```text
barbero-cliente-barberia/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Instalación

```bash
git clone URL_DEL_REPOSITORIO
```

Abre `index.html` en el navegador.

# TechFix — Gestor de incidencias

App web para gestionar incidencias informáticas: crear tickets, buscarlos, filtrarlos por estado y verlos en un dashboard.

## Funcionalidades

- Dashboard con estadísticas
- Búsqueda y filtrado de incidencias por estado
- Creación de incidencias con categoría y prioridad
- Diseño responsive, panel lateral con modo oscuro

## Tecnologías

HTML5, CSS3, JavaScript

## Estructura

```text
techfix/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Instalación

bash
git clone URL_DEL_REPOSITORIO
cd techfix


Abre `index.html` en el navegador. No hace falta instalar nada más.
